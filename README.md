# 🌿 گیاه‌بین (Giyahbin)

برنامهٔ سبک و سریع اندروید برای مسافران و طبیعت‌گردان: از گیاه عکس بگیرید، نام و ویژگی‌ها را ببینید و اگر سمی بود **هشدار تمام‌صفحه** بگیرید.

An ultra-light Android app (≈1 MB, zero dependencies) that identifies plants from a photo and warns loudly when they are toxic. Offline database of 125 plants, filterable by Iranian province.

## امکانات
- 📷 **یک دکمهٔ بزرگ** عکس / گالری → سه انتخاب ساده → گیاهان مشابه با وضعیت سمی/بی‌خطر
- 🆘 دکمه‌های بزرگ قرمز ۱۱۵ و ۱۴۹۰ (مرکز مسمومیت) در همهٔ صفحه‌های مهم
- 🗺 فیلتر **استان** (۳۱ استان، پراکنش منطقه‌ای) و جستجو؛ بدون اینترنت کار می‌کند
- اگر چیزی پیدا نشد یا مشابه سمی بود: «آن را سمی فرض کنید»
- هشدار گیاهان شبیه (شوکران ↔ جعفری، سورنجان ↔ سیر وحشی، …)
- تم تیره/روشن خودکار، فارسی راست‌به‌چپ، بدون تبلیغ و ردیاب

## 💚 تعهد رایگان بودن
> هنگام اولین اجرا، برنامه پیام «تعهد و سلب مسئولیت» را نشان می‌دهد و تا کاربر تیک «می‌پذیرم» را نزند باز نمی‌شود.
«گیاه‌بین» یک پروژهٔ عام‌المنفعه برای آگاهی عمومی است و **همیشه رایگان** می‌ماند: **هرگز** اشتراک، پرداخت، خرید درون‌برنامه‌ای، نسخهٔ پولی، تبلیغ یا فروش داده نخواهد داشت. کد با مجوز MIT آزاد است.

## شناسایی راهنما (آفلاین)
هیچ سرویس رایگان، دقیق و بدون ثبت‌نامِ تشخیص گیاه وجود ندارد؛ پس برنامه به‌جای ارسال عکس به اینترنت، **شناسایی راهنما** دارد: کاربر عکس می‌گیرد (برای مقایسه) و با سه انتخاب ساده (نوع گیاه، رنگ گل/میوه، محل) فهرست گیاهان مشابه و وضعیت سمی بودنشان را می‌بیند. این روش **تخمینی** است و برنامه در این‌باره صریح هشدار می‌دهد. نتیجه: **بدون کلید، بدون اینترنت، بدون مجوز INTERNET.**

## ساخت
```bash
./gradlew assembleRelease     # خروجی: app/build/outputs/apk/release/
```
هر push روی `main` در GitHub Actions یک APK می‌سازد؛ با تگ `v*` در Releases منتشر می‌شود. (APK با امضای دیباگ برای نصب مستقیم است؛ برای فروشگاه کلید خودتان را تنظیم کنید.)

## تصاویر
عکس ۱۲۳ گیاه از Wikimedia Commons با مجوزهای آزاد (CC BY / CC BY-SA / CC0 / مالکیت عمومی) است و نام عکاس زیر هر عکس در برنامه آمده است. فهرست کامل: [data/CREDITS.md](data/CREDITS.md). دریافت: `python tools/fetch_images.py`.
